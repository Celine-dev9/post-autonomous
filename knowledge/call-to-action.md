# Call to Action (CTA) Guidelines

Not every post requires a hard CTA. CTAs should rotate naturally to match the content type and audience engagement stage.

## CTA Types & Frequencies

### 1. Thoughtful Discussion Question (40% of posts)
- Example: *"How is your team handling token budget limits in production agent loops?"*
- Example: *"Do you prefer database locks or queue workers for distributed scheduling?"*

### 2. Bookmark / Save for Later (25% of posts)
- Best for: Tutorials, cheat-sheets, architectures, tool comparisons.
- Example: *"Save this post for your next architecture review."*
- Example: *"Bookmark this blueprint if you're building autonomous pipelines this quarter."*

### 3. Resource / Documentation Link (20% of posts)
- Best for: In-depth breakdowns where full docs or source code exist.
- Example: *"Full architectural details and reference schemas are linked in the documentation below."*

### 4. No CTA / Pure Value (15% of posts)
- End with a strong punchy closing thought or philosophical conclusion.
- Let the quality of the insight stand completely on its own without asking anything of the reader.
